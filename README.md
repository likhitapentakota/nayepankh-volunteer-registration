# NayePankh Foundation Volunteer Registration System

## Project Overview

The NayePankh Foundation Volunteer Registration System is a Full Stack web application developed to simplify volunteer registration and management. The system allows users to register as volunteers by providing their personal details and skills.

The application dynamically displays registered volunteers and maintains a count of total volunteers.

## Features

* Volunteer Registration Form
* Display Registered Volunteers
* Total Volunteer Counter
* Skills Management
* Responsive User Interface
* Frontend and Backend Integration

## Technologies Used

### Frontend

* HTML5
* CSS3
* JavaScript

### Backend

* Node.js
* Express.js

## How to Run the Project

### Step 1: Install Dependencies

npm install

### Step 2: Start the Server

node server.js

### Step 3: Open the Application

Open index.html in your browser.
